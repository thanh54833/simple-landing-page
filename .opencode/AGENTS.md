# Guide for agents — opencode config + gate routers

## OVERVIEW
Canonical gate routers (`command/`) and the opencode agent/model config. Routers are thin: frontmatter, `$ARGUMENTS`, gate steps. Procedure lives in skills.

## STRUCTURE
```
.opencode/
├── CHANGELOG.md         # root log: structure/config changes, newest-first per date
├── command/             # 8 routers: intent, spec, adr, plan, implement, verify, ship, impeccable
│   └── CHANGELOG.md     # router changes, dated headings
├── oh-my-openagent.json # agent/category model map; mirrors .omo/omo.jsonc
├── package.json         # @opencode-ai/plugin (gitignored with node_modules)
└── node_modules/        # ignore when exploring
```

## WHERE TO LOOK
| Task | Location | Notes |
|------|----------|-------|
| Gate chain | `command/{intent,spec,adr,plan,implement,verify,ship}.md` | one router per stage |
| UI design entry | `command/impeccable.md` | routes into the vendored impeccable skill |
| Router format | any file in `command/` | `description`, `argument-hint`, `## User Input`, numbered steps |
| pi mirror | `.pi/prompts/` | generated by `make agents_sync` |
| Client wiring | root `opencode.json` | plugins, `skills.paths`, generated `mcp` block |
| Track history | `CHANGELOG.md` (root) | newest-first per date; update khi đổi `oh-my-openagent.json`/cấu trúc (sync thường không ghi) |

## CONVENTIONS
- A router stops on a failed gate (no accepted intent → suggest `/intent`) and never restates procedure.
- `command/` is generated from `.agents/.commands/`: `make agents_sync` copies each router here and into `.pi/prompts/<name>.md`, and prunes deleted ones; `make agents_sync-check` fails on drift (`make commands` is the old alias).
- Quote `argument-hint` when it starts with `[`, or YAML parses it as a list.
- Model config here is mirrored by `.omo/omo.jsonc` (plus its `[opencode]` overlay); change both together.

## ANTI-PATTERNS
- Don't write procedure in a router — route to the skill.
- Don't add a router only under `.claude/commands/`; pi never sees it.
- Don't edit `command/CHANGELOG.md` for skill-only changes.
